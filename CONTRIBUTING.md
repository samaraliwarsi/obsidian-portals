# Contributing

Thanks for wanting to improve Portals!

## Development

1. Clone the repo.
2. Run `npm install`.
3. Run `npm run dev` to build in watch mode.
4. Copy or symlink the built files to your vault's `.obsidian/plugins/portals/` folder.

## Pull requests

- Keep changes small and focused.
- Follow the existing code style.
- Test on both desktop and mobile when possible.
